# USB Formatter (FAT32 + exFAT)

Build sans PC : crée un dépôt GitHub, envoie tous ces fichiers (en gardant les dossiers),
puis onglet Actions > "Build APK" > télécharge l'artefact `UsbFormatter-apk` (contient app-debug.apk).

Utilisation : brancher la clé en OTG, ouvrir l'appli, Détecter, choisir le format, Formater.
